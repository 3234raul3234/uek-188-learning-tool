# ÜK 188 Lern-Tool

> 🚧 **Beta-Version:** Das Tool wird noch entwickelt. Es kann Fehler geben, und Aufgaben können sich noch ändern. Probleme oder Ideen bitte unter [Issues](https://github.com/3234raul3234/uek-188-learning-tool/issues) melden.

Ein Übungsprogramm für den **ÜK 188** (Services betreiben, warten und überwachen).
Du bekommst eine Windows-VM mit **15 Aufgaben**. Das Programm sagt dir sofort, ob du sie richtig gelöst hast.

---

## Installieren (3 Schritte)

**1. VMware installieren**
Lade **VMware Workstation** herunter (gratis) und installiere es: https://www.vmware.com/products/desktop-hypervisor/workstation-and-fusion

**2. Windows 11 herunterladen**
Öffne https://www.microsoft.com/software-download/windows11 und lade bei **„Windows 11-Datenträgerimage (ISO)“** die ISO-Datei herunter (ca. 7 GB).

**3. Dieses Tool starten**
- Klick oben auf den grünen Knopf **Code** und dann auf **Download ZIP**
- Entpacke die ZIP-Datei (Rechtsklick → *Alle extrahieren*)
- Doppelklick auf **`START.cmd`** (warnt Windows, klick auf *Weitere Informationen* → *Trotzdem ausführen*)
- Wähle die Windows-ISO aus Schritt 2 aus

**Fertig.** Windows installiert sich jetzt in der VM von selbst. Warte ca. **30 Minuten** und klick in der Zeit nichts an.

---

## Benutzen

1. Melde dich in der VM an. Benutzer: **Administrator**, Passwort: **Lab188-uek**
2. Doppelklick auf **Lab-Trainer UeK 188** auf dem Desktop
3. Links eine Aufgabe wählen und dann:
   **Lab starten** → **Ordner öffnen** → Aufgabe lösen → **Prüfen**

Grün heisst richtig, rot heisst falsch, und unter Rot steht ein Tipp.

Extra-Knöpfe:
- **Doku erstellen**: schreibt dir einen Text für deine Dokumentation
- **Quiz**: fragt dich Theorie ab

---

## Gut zu wissen

- Windows ist **nicht aktiviert**. Das ist für eine Übungs-VM okay (unten rechts erscheint ein Wasserzeichen).
- Das Passwort ist nur für diese VM. Verwende es nirgends sonst.
- Etwas kaputt gemacht? Doppelklick auf `START.cmd` und die VM neu bauen lassen.
